# AI4SEC 万题集：知识范围规划

## 一、题库定位

目标是构建一套持续扩充的学习题库，支持从 AI 基础、大语言模型、Agent，到 AI 解决安全问题的完整学习过程。“万题集”指万题级及以上的题库，题量可以继续扩展到数万题，不设置固定上限。

题目分为两类：

- **通用基础**：数学、编程、机器学习、深度学习、大语言模型、RAG 和 Agent 等。基础题可以独立考查原理和工程能力。
- **AI4SEC 应用**：把上述技术用于安全数据分析、威胁检测、恶意软件分析、漏洞检测、威胁情报和安全运营等。

安全领域知识按任务需要纳入，例如理解告警字段、漏洞标签和攻击行为；同时安排跨领域综合案例，连接模型原理、数据、工具和安全工作流。

各方向的题量由知识点、资料质量和实际学习需求决定，不设置固定配额。**当前应用已有 198 张卡片；万题集尚未制作完成。**

## 三、各方向知识点

### 01. 数学与统计基础

- **线性代数**：标量、向量、矩阵、张量；维度与形状；矩阵乘法、转置、范数、内积和相似度。
- **微积分**：导数、偏导数、链式法则、梯度，以及它们在反向传播中的作用。
- **概率**：条件概率、独立性、贝叶斯公式、常见概率分布、期望和方差。
- **统计**：采样、均值与中位数、方差、置信区间、假设检验及结果解释。
- **优化**：目标函数、局部最优、梯度下降、学习率、约束和正则化的基本作用。
- **信息与图**：熵、交叉熵、KL 散度的直观含义；图、节点、边、邻居和路径的基础概念。
- **实验思维**：对照组、样本量、随机性、偏差、相关性与因果性的区别。

### 02. Python 与数据工程

- **Python 基础**：容器、函数、异常处理、生成器、模块、类型提示与常见调试方式。
- **数据处理**：NumPy 数组形状与广播；Pandas 读取、筛选、合并、缺失值和分组统计。
- **文件与格式**：JSON、JSONL、CSV、Parquet、编码、路径和批量数据读写。
- **训练工具**：PyTorch 张量、Dataset、DataLoader、模型保存和加载。
- **实验环境**：虚拟环境、依赖版本、随机种子、配置文件和实验记录。
- **接口使用**：HTTP、JSON 请求和响应、流式输出、超时、重试与结果解析。
- **工程习惯**：日志、测试、版本管理、数据版本与实验可复现性。

### 03. 机器学习基础

- **任务类型**：回归、二分类、多分类、多标签分类、聚类和异常检测。
- **监督学习**：逻辑回归、决策树、随机森林、梯度提升树、支持向量机等常见模型。
- **无监督学习**：K-means、密度聚类、Isolation Forest、相似度与异常分数。
- **特征工程**：数值与类别特征、编码、归一化、缺失值、特征选择和特征重要性。
- **数据划分**：训练集、验证集、测试集、交叉验证、时间切分、分组切分和数据泄漏。
- **效果评估**：混淆矩阵、精确率、召回率、F1、ROC、PR 曲线、平均精确率和概率校准。
- **类别不平衡**：类别权重、训练集重采样、阈值选择和成本敏感评估。
- **模型诊断**：欠拟合、过拟合、数据漂移、基线比较、消融实验和错误分析。

### 04. 深度学习基础

- **神经网络**：层、参数、激活函数、前向计算、损失函数和反向传播。
- **训练过程**：梯度、计算图、批次、epoch、优化器与参数更新。
- **常见损失**：交叉熵、二元交叉熵、均方误差及适用任务。
- **优化方法**：SGD、Adam、学习率调度、预热、梯度裁剪和梯度累积。
- **稳定与泛化**：权重初始化、残差、归一化、Dropout、正则化和早停。
- **常见结构**：CNN、RNN、LSTM、图神经网络的基本思想和适用数据。
- **训练实践**：GPU 显存、混合精度、数据吞吐、检查点和故障定位。
- **模型诊断**：损失不下降、梯度异常、训练与验证差距、参数和输入形状错误。

### 05. NLP 与 Transformer

- **文本任务**：文本分类、序列标注、实体识别、关系抽取、摘要和问答。
- **分词与词表**：字符、词和子词；BPE、WordPiece、特殊 token 与未知词。
- **文本表示**：词向量、上下文表示、语义向量和向量相似度。
- **注意力**：Query、Key、Value、缩放点积注意力、注意力权重和多头注意力。
- **位置与掩码**：位置编码、RoPE、padding mask、因果 mask 和上下文长度。
- **Transformer 结构**：Embedding、前馈网络、残差连接、归一化和堆叠层。
- **模型结构比较**：Encoder-only、Decoder-only 和 Encoder-Decoder 的输入与训练目标。
- **实践题**：张量维度、注意力矩阵、掩码方向、token 数量和长文本截断。

重点参考 Happy-LLM 的 NLP、Transformer 和预训练语言模型章节，并补充可用于安全文本和代码处理的案例。

### 06. 大语言模型训练与推理

- **预训练**：语料处理、分词、训练目标、批次、损失和检查点。
- **模型适配**：指令微调、SFT、领域数据构造和训练集质量。
- **参数高效微调**：LoRA、QLoRA、冻结参数、适配器和训练资源估算。
- **偏好与强化学习**：RLHF、DPO、GRPO 的基本目标和适用场景。
- **推理与生成**：自回归生成、temperature、top-k、top-p、停止条件和结构化输出。
- **推理优化**：KV Cache、量化、批处理、上下文长度与显存开销。
- **模型评测**：基准数据、答案质量、稳定性、幻觉、模型版本和复现条件。
- **模型选型**：能力、上下文、响应时间、部署环境、成本与许可条件。

### 07. 检索、向量数据库与 RAG

- **知识准备**：文档解析、清洗、去重、切块、元数据和版本管理。
- **向量基础**：Embedding、相似度、距离、向量维度和语义检索。
- **检索方法**：关键词检索、BM25、向量检索、近似最近邻、混合检索和重排。
- **索引与更新**：向量库、索引构建、增量更新、删除、来源过滤和过期内容处理。
- **生成过程**：上下文组装、引用、答案约束、无答案处理和多轮问答。
- **评估**：Recall@K、MRR、NDCG、检索命中、答案正确性、引用支持和上下文覆盖。
- **问题诊断**：找不到资料、切块不完整、版本错误、资料冲突和模型误读。
- **安全应用**：漏洞公告、规则文档、历史事件与威胁报告知识库。

### 08. Agent 原理与设计

- **Agent 基本组成**：目标、模型、状态、环境、动作、观察、工具和反馈。
- **工作流与自主决策**：固定流程、条件分支、循环、动态规划及适用边界。
- **规划与执行**：任务拆解、计划生成、执行步骤、子任务依赖和计划调整。
- **推理与行动模式**：ReAct、计划—执行、反思、验证和迭代。
- **工具调用**：工具描述、参数 schema、函数调用、结构化结果、工具选择和错误反馈。
- **记忆**：短期上下文、长期记忆、外部存储、检索、更新和遗忘策略。
- **上下文工程**：系统指令、任务状态、证据压缩、历史裁剪和上下文预算。
- **多智能体**：角色分工、协调、通信、共享状态、结果汇总和协作失败。
- **人机协作**：人工确认、任务移交、审批节点和可解释输出。
- **协议与扩展**：MCP、A2A 等协议的概念，以及工具、上下文和智能体之间的连接方式。

重点参考 Hello-Agents、Microsoft AI Agents for Beginners 等教程；基础题单独考查 Agent 原理，应用题再结合安全任务。

### 09. Agent 工程与评测

- **状态与执行**：状态机、图工作流、持久化、中断恢复和任务重放。
- **工具工程**：参数校验、返回格式、超时、重试、限流和幂等。
- **异步与并发**：并行任务、依赖关系、队列、取消和资源控制。
- **可靠性**：错误分类、降级、循环终止、上下文溢出和工具不可用处理。
- **观测与调试**：轨迹、日志、调用链、耗时、token 使用、成本和版本追踪。
- **评测方法**：任务成功率、步骤正确性、工具调用、证据质量、人工评审与回归测试。
- **运行管理**：权限范围、沙箱、人工审批、预算控制和部署配置。
- **实战问题**：Agent 重复调用工具、误选工具、记忆过期和多轮状态丢失。
- **框架实践**：使用 Agent 工作流框架构建状态、节点、工具、记忆和评测流程，关注框架共性与版本差异。

### 10. 安全数据与特征

- **网络数据**：PCAP、网络流、DNS、HTTP、TLS 元数据及常见日志字段。
- **主机与身份数据**：进程、父子进程、文件操作、登录、账号和资产信息。
- **其他输入**：源代码、二进制文件特征、邮件、网址、告警与威胁报告。
- **日志处理**：字段解析、统一结构、时间戳、事件关联、去重和数据质量。
- **标签与样本**：标注来源、正常／恶意／未知样本、弱标签、标签延迟和噪声。
- **安全特征**：统计、时间窗口、序列、文本、代码结构与图关系。
- **实验切分**：时间、主机、攻击活动、项目、家族与相似样本泄漏。
- **数据治理**：数据来源、版本、访问权限、脱敏与可复现记录。

### 11. AI 威胁与异常检测

- **网络威胁**：异常连接、扫描行为、暴力尝试、异常流量及加密流量元数据分析。
- **DNS 与域名**：异常查询、可疑域名、DGA 特征和主机查询行为。
- **异常通信**：疑似 C2、异常外联、数据外传线索及多事件关联。
- **主机行为**：进程序列、命令行为、文件变化和主机行为基线。
- **身份与账号**：异常登录、账号行为变化、访问关系和风险排序。
- **建模方法**：分类、异常检测、时序模型、图模型与规则结合。
- **检测评估**：不同攻击类型、误报、漏报、告警量、跨环境与时间外表现。
- **真实场景**：资产背景、业务变化、重复告警、分析证据和人工确认。

### 12. AI 恶意软件与钓鱼检测

- **文件静态特征**：PE／ELF 结构、导入信息、字符串和字节统计。
- **动态行为**：隔离环境中的进程、文件、注册表和网络行为。
- **恶意软件模型**：分类、聚类、家族识别、未知样本和新家族评估。
- **钓鱼检测**：网址词法、域名、邮件文本、页面内容和截图等特征。
- **数据问题**：标签可靠性、样本家族、域名／模板去重和时间变化。
- **分析输出**：风险分数、依据、误报分析以及与人工分析的配合。

### 13. AI 代码漏洞检测

- **代码表示**：token、函数、调用关系、AST、CFG、数据流和程序图。
- **检测方法**：规则与静态分析基线、传统分类、代码模型、图模型和大模型辅助审计。
- **漏洞场景**：输入处理、注入、访问控制、内存安全和反序列化等常见问题的检测线索。
- **上下文**：跨函数调用、数据来源、校验条件、代码截断和项目依赖。
- **数据集与标签**：Devign、CodeXGLUE、PrimeVul 等基准，修复前后代码和标签噪声。
- **评估**：项目／时间切分、相似代码去重、成对样本、定位准确性、误报和漏报。
- **审计工作流**：定位可疑代码、解释触发条件、提出待验证问题和人工复核。

### 14. AI 辅助模糊测试

- **基本概念**：fuzz target、harness、输入、覆盖率和 sanitizer。
- **生成与修复**：大模型生成测试入口、编译错误修复、API 使用核对。
- **测试质量**：目标代码是否执行、有效覆盖、新增覆盖和资源成本。
- **崩溃处理**：崩溃归因、去重、输入缩减、复现和版本记录。
- **实验评估**：与人工目标比较，区分 harness 问题和目标代码问题。

### 15. AI 威胁情报

- **情报对象**：IP、域名、哈希、漏洞编号、组织、工具和攻击行为。
- **信息抽取**：实体识别、关系抽取、事件抽取与结构化输出。
- **ATT&CK 映射**：战术、技术、子技术、具体行为和证据关联。
- **情报关联**：实体去重、时间线、知识图谱和跨报告关联。
- **质量与溯源**：资料来源、时间、可信度、冲突、版本和人工复核。
- **评估**：实体／关系／技术映射的精确率、召回率及原文证据定位。

### 16. AI 安全运营与应急响应

- **告警研判**：日志汇总、资产上下文、风险判断和待验证事项。
- **告警关联与排序**：重复告警、事件聚合、优先级和分析容量。
- **事件摘要**：时间线、受影响对象、关键证据和结论引用。
- **调查辅助**：安全知识检索、日志查询、工具结果解读和报告草稿。
- **检测内容辅助**：根据需求辅助生成或解释检测规则，并通过样本验证。
- **人机协作**：分析人员复核、处置审批和调查过程留痕。
- **效果衡量**：有效发现、误报漏报、调查时间和人工工作量。

### 17. AI4SEC 评估与落地

- **项目设计**：问题定义、任务边界、数据来源、基线和成功指标。
- **模型评估**：时间外／跨项目／跨环境测试，误报量、漏报与成本。
- **大模型和 Agent 评估**：结论正确性、证据支持、工具调用、完成率和稳定性。
- **系统工程**：离线与在线流程、接口、任务队列、模型版本和数据版本。
- **监控与维护**：数据漂移、模型漂移、告警反馈、重新训练和回归测试。
- **实际部署**：响应时延、资源预算、权限、隐私、人工复核和故障降级。
- **综合案例**：从需求、数据、建模、实验到上线复盘的完整 AI4SEC 项目题。

### 18. 多模态与其他 AI 方法

- **计算机视觉**：图像表示、特征提取、分类、目标检测和视觉模型的基本评估。
- **多模态模型**：图文输入、视觉语言模型、图像理解和多模态检索。
- **文档理解**：OCR、版面解析、图表与表格提取，以及扫描文档的知识整理。
- **语音与音频**：语音识别、音频表示和语音内容分析的基础方法。
- **图学习**：图表示、节点与边特征、图神经网络及关系数据建模。
- **强化学习**：状态、动作、奖励、策略及训练与评估的基本概念。
- **安全应用**：钓鱼页面截图、文档分析、语音诈骗线索和安全实体关系等场景。

## 四、题目类型与难度

每个方向混合以下题型，避免万题集只包含概念定义：

| 题型 | 学习目标 | 示例 |
| --- | --- | --- |
| 概念与原理 | 理解定义、机制和前提 | 说明因果注意力掩码的作用 |
| 比较与选型 | 区分相近方法和适用条件 | 比较关键词检索与向量检索 |
| 计算与推导 | 理解公式、维度和指标 | 根据混淆矩阵计算精确率 |
| 代码与配置 | 读懂实现并定位错误 | 判断工具调用参数为何校验失败 |
| 故障排查 | 分析异常现象与原因 | 排查 Agent 反复调用同一工具 |
| 设计与权衡 | 选择流程、指标和系统方案 | 为告警排序选择评估方式 |
| 安全场景 | 将模型或 Agent 应用于实际任务 | 用日志与资产信息辅助研判 |
| 综合案例 | 串联数据、模型、工具和评估 | 设计一个可追溯的漏洞分析助手 |

每题标记为**入门、进阶或实践**，并设置一个主要知识点。具体比例应根据来源资料和实际难度校准。

## 五、分类、去重和资料来源

每题至少记录：稳定编号、一级方向、二级主题、知识点、标签、难度、题型、问题、答案、解析、示例和来源。涉及代码、公式或实验条件的题目，补充必要的输入、前提和版本信息。

同一知识点的重复问法归并到同一主卡，保留不同来源、补充解释和例子；同一主题下针对不同原理、条件或应用的问题可以分别保留。新增题目时先做精确和相似度检查，再人工确认语义，不能通过改变措辞或重复模板凑数量。

题库按来源和章节持续增补：新资料带来新的概念、方法、代码实践或案例时，可以增加新卡；同一知识点有更好的解释时，优先补充到已有卡片。题量和分类随内容增长调整，不以一万题作为终点。
