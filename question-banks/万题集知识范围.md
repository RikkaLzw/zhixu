# AI4SEC 万题集：知识范围规划

## 一、题库定位

目标是构建一套持续扩充的学习题库，支持从 AI 基础、大语言模型、Agent，到 AI 解决安全问题的完整学习过程。“万题集”指万题级及以上的题库，题量可以继续扩展到数万题，不设置固定上限。

题目分为两类：

- **通用基础**：数学、编程、机器学习、深度学习、大语言模型、RAG 和 Agent 等。基础题可以独立考查原理和工程能力，不要求每题都套用安全场景。
- **AI4SEC 应用**：把上述技术用于安全数据分析、威胁检测、恶意软件分析、漏洞检测、威胁情报和安全运营等。

安全领域知识按任务需要纳入，例如理解告警字段、漏洞标签和攻击行为；同时安排跨领域综合案例，连接模型原理、数据、工具和安全工作流。

各方向的题量由知识点、资料质量和实际学习需求决定，不设置固定配额。当前覆盖与未完成情况见 [批次进展](批次进展.md)。

面试复习优先保留跨项目可迁移的基础概念、原理、常用工具及典型易错点。论文可以作为知识依据；需要记忆特定实验数值、冷门模型内部组件或某数据集发布细节的题，经过人工判断后可放入“研究拓展”，供有专项需求的读者选择。面试适用性审计仍在持续，未标记为拓展不代表已逐张确认是高频面试题。

## 三、各方向知识点

### 01. 数学与统计基础

- **线性代数**：标量、向量、矩阵、张量；维度与形状；矩阵乘法、转置、范数、内积、相似度和奇异值分解。
- **微积分**：导数、偏导数、链式法则、梯度、方向导数、雅可比与 Hessian，以及它们在反向传播中的作用；矩阵梯度约定、迹与二次型求导、矩阵逆／行列式／log-det 导数、Frobenius 范数和矩阵最小二乘梯度。
- **概率**：条件概率、独立性、条件期望与全方差、贝叶斯公式、顺序更新与赔率、Beta—二项共轭更新、SciPy 多元正态分布接口、指数分布与泊松到达间隔、常见概率分布、期望、方差与离散马尔可夫链。
- **统计**：采样、均值与中位数、方差、最大似然估计及其前提、样本均值极限定理、四分位距和中位数绝对偏差、Pearson 与秩相关、置信区间与 Bootstrap 重采样接口、假设检验、独立与配对 t 检验、Shapiro 正态性检验、列联表独立性、Fisher 精确检验、Mann–Whitney U 独立样本检验、Wilcoxon 配对符号秩检验与 McNemar 成对分类检验、多重比较与假发现率及结果解释。
- **优化**：目标函数、局部最优、凸性、LogSumExp 数值计算、梯度下降、学习率、约束和正则化的基本作用；拉格朗日函数、对偶函数、弱／强对偶、Slater 条件及 KKT 原始可行、对偶可行、驻点和互补松弛条件，注明凸性与约束资格对最优性结论的作用。
- **信息与图**：熵、交叉熵、KL 散度与 Jensen–Shannon 距离的含义及计算前提；图、节点、边、邻居、连通性和路径的基础概念。
- **实验思维**：对照组、样本量、随机性、偏差、相关性与因果性的区别。
- **离散数学与计算机科学证明**：命题与谓词逻辑、量词、集合与幂集、函数的单射／满射／双射、二元关系与等价类、偏序与 Hasse 图、直接证明／反证／归纳法、结构归纳、循环不变式、鸽巢原理、乘法计数和容斥。
- **因果推断**：潜在结果、ATE 与 ATT、效应异质性、随机分配、因果 DAG、混杂／中介／碰撞点、后门调整、重叠性、倾向评分、双重差分平行趋势、工具变量假设与回归断点设计；识别结论依赖明确的研究设计前提。

### 03. 机器学习基础

- **任务类型**：回归、二分类、多分类、多标签分类、聚类和异常检测。
- **监督学习**：逻辑回归、K 近邻分类、决策树、随机森林、梯度提升树、直方图梯度提升分类器、CatBoost 类别特征与有序目标统计、LightGBM 叶优先树与分类器接口、支持向量机等常见模型。
- **无监督学习**：K-means、DBSCAN 与 HDBSCAN 密度聚类、Isolation Forest、轮廓系数与调整兰德等聚类评估、相似度与异常分数。
- **特征工程**：数值与类别特征、多项式与交互特征、编码、归一化、缺失值、词袋、TF-IDF 与 HashingVectorizer 哈希文本特征、特征选择和特征重要性。

- **效果评估**：混淆矩阵、MCC、精确率、召回率、F1、ROC、PR 曲线、平均精确率、概率校准曲线、Brier 分数接口与缩放口径、温度缩放与校准器、交叉验证分数置换检验。
- **类别不平衡**：正例与未标注样本学习及 SCAR 假设、类别权重、训练集重采样与 SMOTE、阈值选择、scikit-learn 决策阈值调优接口和成本敏感评估。
- **模型诊断**：欠拟合、过拟合、学习曲线与验证曲线、数据漂移、基线比较、消融实验、错误分析、局部模型解释及 PDP／ICE 部分依赖分析。
- **常用接口**：scikit-learn 的数据切分、预处理、ColumnTransformer 分列变换、特征选择与重要性、训练与预测、SGD 增量学习、Pipeline、交叉验证、随机参数搜索及评估函数；理解参数前提和数据泄漏风险。

### 04. 深度学习基础

- **神经网络**：层、参数、激活函数、前向计算、损失函数和反向传播。
- **训练过程**：梯度、计算图、批次、epoch、优化器与参数更新；PyTorch 张量索引、广播、二维卷积与分组、二维最大池化与反池化、变长序列、自动微分与 torch.func 函数变换、模块、Embedding 与 EmbeddingBag、余弦相似度、缩放点积注意力、多头注意力掩码与输出形状、插值缩放、损失和优化器常用接口。

## 四、题目类型与难度

每个方向混合以下题型，避免万题集只包含概念定义：

| 题型 | 学习目标 | 示例 |
| --- | --- | --- |
| 概念与原理 | 理解定义、机制和前提 | 说明因果注意力掩码的作用 |
| 比较与选型 | 区分相近方法和适用条件 | 比较关键词检索与向量检索 |
| 计算与推导 | 理解公式、维度和指标 | 根据混淆矩阵计算精确率 |
| 代码与配置 | 读懂实现并定位错误 | 判断工具调用参数为何校验失败 |
| 故障排查 | 分析异常现象与原因 | 排查 Agent 反复调用同一工具 |
| 设计与权衡 | 选择流程、指标和系统方案 | 为告警排序选择评估方式 |
| 安全场景 | 将模型或 Agent 应用于实际任务 | 用日志与资产信息辅助研判 |
| 简短场景 | 在明确前提下识别一个关键知识点 | 指出漏洞分析结论应保留哪类证据 |

每题标记为**入门、进阶或实践**，并设置一个主要知识点；应用中「入门」显示为「基础」。全库 10021 张主卡已按核心概念、机制边界和实际应用场景完成阶段复核，当前基础 2381 张、进阶 7194 张、实践 446 张。难度是相对判断；学习设置支持自由开启阶段，研究拓展是独立范围。

计算、代码、设计和安全场景题仅保留能独立理解、简短作答的知识点；不收录复杂计算、大段代码分析或需要长篇论述的综合案例。答案优先为 1—3 句话。

## 五、分类、去重和资料来源
